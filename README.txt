BAG OF CRISPS — PUBLIC ORDERING WEBSITE

Files:
- index.html
- styles.css
- script.js
- logo.png

This is a static website. It does not create invoices or store customer orders on a server.
When a customer submits the form, WhatsApp opens with the order message addressed to:
+91-9582379369

For GitHub Pages:
1. Create a new GitHub repository.
2. Upload all four files.
3. In Settings > Pages, choose Deploy from branch, select main and /root.
4. Open the generated Pages URL and share it with customers.

To change menu/prices, edit menuData in script.js.
